# Tajweed annotations

`tajweed.hafs.uthmani-pause-sajdah.json` contains per-character tajweed
annotations for the complete Hafs Quran (6,236 ayahs).

- Source: https://github.com/quran/quran-tajweed
- Upstream license: CC BY 4.0
- Downloaded from the upstream `master` branch.
- SHA-256: `151D616AD37A4CC21A80F20D5E1104C5B408375107DDD4D71247DEA4C05EBF67`

This file is **Hafs-only**. It must not be applied to Warsh or Qaloon text;
those narrations require their own independently reviewed annotations.
